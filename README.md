# AJU PHARMA POINT — Version 1.0

Static GitHub Pages website inspired by the existing AJU PHARMA POINT Google Site.

## Deploy
1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. GitHub → Settings → Pages → Deploy from branch → main → / (root).
4. Open the generated GitHub Pages URL.

## Customize
- Replace placeholder semester resource links in `semesters/`.
- Replace the Malik AI URL in `index.html` with your exact bot URL if needed.
- Add your own profile image under `assets/` and update the profile card.
